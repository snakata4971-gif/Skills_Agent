# おもちゃ・ホビー検品

## 撮影指示
- 箱の正面・背面・天面（型番やバーコードが写るように）
- 箱の角4か所のアップ（つぶれ・破れの確認用）
- 未開封の場合はシール・シュリンク（ビニール包装）の状態
- 開封品の場合は、中身とパーツを並べた全体写真

## 判定項目と基準
### 商品の一致
- 商品名・型番・シリーズ名が顧客写真と一致するか。
- 同シリーズの別番号・別カラーは NG（別商品 または 色違い）。

### 箱の状態（コレクション品では箱も商品価値）
- 顧客写真にない箱のつぶれ・へこみ・破れ・水濡れ跡は NG（汚破損）。
- 輸送用の外箱（段ボール）の傷は OK。商品の箱そのものの損傷は NG。
- つぶれの程度が写真で判断できない場合は 要確認。

### 未開封・開封
- 顧客写真で未開封（シール・シュリンクあり）なのに、現物が開封されている場合は NG（汚破損）。
- シュリンクの破れは 要確認（輸送中の破れかどうか人の判断が必要）。

### パーツ・付属品
- 申告・顧客写真にあるパーツ、説明書、特典がそろっているか。欠品は NG（付属品欠品）。

### 塗装・破損
- フィギュア本体の破損、塗装はげ、パーツの折れは NG（汚破損）。
