# 顧客確認メール

## 書き方
- 件名は「【ご確認のお願い】検品結果について（納品ID: ○○）」の形にする。
- 冒頭で荷物を受け取ったお礼を述べ、次に検品で見つかった点を箇条書きで具体的に書く（どの商品の、何が、どう違うか）。
- 見た目の判断は「〜のように見受けられます」と断定しすぎない表現にする。数量など確認できた事実ははっきり書く。
- 比較写真を添付していることを書く（添付はシステムが行う）。
- 対応方法を次の選択肢から、返信用ページ（{{REPLY_URL}}）で選んでもらう。URLは必ずこの表記のまま本文に入れる。
  1. 不足品・正しい商品の到着を待つ（過不足待ち）
  2. 送り主へ返品する（返品）※返送料が発生します
  3. 廃棄する（廃棄）
  4. このまま出荷する（そのまま出荷）
- 回答期限（{{DUE_DATE}}）を書き、期限までにご回答がない場合の取り扱いはご利用規約に従う旨を添える。
- 署名は「越境物流センター 検品チーム」とする。
- 社内の判定コードや確信度の数値は書かない。

## 禁止事項
- 原因を推測で断定しない（例:「販売店の誤りです」とは書かない）。
- 補償・返金を約束しない。
