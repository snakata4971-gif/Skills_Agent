# 顧客C-1002 固有ルール（顧客SOPより）

このスキルは共通・カテゴリ別スキルより優先する。

## 撮影指示
- 箱の6面すべて

## 判定基準
- 再販売する商品のため、箱のへこみ・角つぶれは軽微でも NG（汚破損）として顧客に連絡する。
- 初回特典（カード・ステッカー等）が申告に含まれる商品は、特典の有無を必ず確認する。ない場合は NG（付属品欠品）。
